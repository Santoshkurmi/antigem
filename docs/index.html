App Variants

Choose Your Build Flavor

Download the standalone all-in-one edition or connect to your existing Termux setup.

RECOMMENDED

Termux Flavor

com.termux (antiGem-termux-release.apk)

All-in-one standalone environment. You do NOT need the Termux app installed. AntiGem natively runs its own full Linux environment, package manager (pkg/apt), shell, and compilers in its private sandbox.

  • ✓ Standalone zero-setup installation
  • ✓ Embedded Linux rootfs & package manager
  • ✓ Built-in compiler toolchains & Glibc
  • ✓ Direct foreground service support
Download Termux APK

Standard Flavor

com.antigem

Connects to an external Termux application already installed on your device. Runs agy_ide_bridge inside external Termux and connects the AntiGem UI over localhost.

  • ✓ Integrates with existing Termux setup
  • ✓ Shared package tree with system Termux
  • ✓ Customizable bridge ports

Key Capabilities

Engineered for Developers

A complete workstation engineered to bridge desktop-grade coding to mobile.

🤖

Autonomous Agentic AI

  • Direct Wire gRPC Hub: Type-safe, low latency stream with Square Wire.
  • Live Streamed Reasoning: Real-time tokens, thought collapse & subagent tracking.
  • Model Switching: Gemini 3.7 Flash/Pro, Claude 3.5 Sonnet, GPT-4o, and custom models.
  • Interactive Prompts: Native multiple-choice modals & tool approval.
🐧

Native Linux Subsystem

  • High-Performance PTY: Terminal emulator with quick-keys and font sizing.
  • Full Linux Stack: Pre-configured bash, Python, Node.js, Git, Go, and Glibc.
  • Terminal MCP: Autonomous command execution with continuous foreground output.
📝

Mobile IDE Code Editor

  • Syntax Highlighting: Python, Go, Kotlin, Java, Rust, JS/TS, HTML/CSS, JSON.
  • Productivity Controls: Multi-tab switcher, find/replace, undo/redo, auto-indent.
  • Workspace File Explorer: Instant directory browsing and project switching.
🌐

Web Browser & Automation

  • Built-in Browser: In-app preview for local dev servers (Vite, Next, Flask, etc.).
  • Browser Automation MCP: Inspect DOM elements, click, type, and verify UI workflows.
🎨

Dynamic Chat Artifacts

  • Interactive Diffs: Expandable git-style diffs and copyable code blocks.
  • Mermaid Diagrams: Hardware-accelerated flowcharts and state diagrams.
  • Picture-in-Picture (PIP): Floating overlay for multi-tasking across Android.
🛡️

Full Backup & Updater

  • Rootfs Backup: One-tap export of installed Linux packages and dotfiles.
  • Database Backup: Export transcripts, settings, and credentials to phone storage.
  • In-App Updater: One-tap version checking and APK updates.
Source & Compilation

Build From Source

Clone and compile AntiGem directly with your favorite toolchain.

📋 Prerequisites

  • JDK 17+ Java Development Kit
  • API 35 Android SDK API 35 & Build Tools 35.0.0+
  • Go 1.23+ For compiling agy_ide_bridge
  • Gradle 8.11+ Build automation system
bash — antigem-build
# 1. Clone the repository $ git clone https://github.com/santoshkurmi/antigem.git $ cd antigem # 2. Build recommended Termux flavor APKs $ ./gradlew assembleTermuxDebug $ ./gradlew assembleTermuxRelease # 3. Or build all APKs via script $ ./scripts/build_all_apks.sh
